Prompt: Which control should I use to change the oscillator octave? Describe where it is and what it does.

Response:

Use the OCTAVE selector to change the oscillator octave.

It is in the Synthesizer section, at the upper-left area of the main panel. In the manual’s synthesizer panel diagram, it is control number 1, just to the left of the VCO waveform selector.

What it does: the OCTAVE selector “specifies the VCO pitch in steps of an octave.” The manual notes that with the 64' setting, the ribbon keyboard pitch range is A0–D2.

One important limitation: if the RANGE select switch is set to WIDE, the manual says the OCTAVE selector will be ignored.
