Prompt: Create a structured description of the noise level.

Response:

The noise level is controlled by the NOISE knob. It adjusts how much white noise is mixed into the VCO output.

Where it is: in the Synthesizer section, it is control 3 in the manual’s panel diagram. On the top panel, it is in the upper-left synth control area, near the VCO controls and close to the OCTAVE selector and WAVE select switch.

What it does: turning the NOISE knob changes the level of the white noise generator mixed with the oscillator sound. The manual documents it as “adjusts the level of white noise that’s mixed with the VCO output.” It does not give numerical values, ranges, or a dB scale.
