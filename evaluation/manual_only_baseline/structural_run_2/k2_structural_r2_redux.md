Prompt: Create a structured description of the noise level.

Response:

The NOISE knob controls the level of white noise mixed with the VCO output. Turning it up adds more white noise to the synthesizer sound; turning it down reduces or removes that noise component.

Where it is: In the synthesizer section, it is control 3 in the manual’s panel diagram. It sits in the VCO area, near the OCTAVE selector, WAVE select switch, and RANGE select switch.

Structured description

Item	Description
Official control name	NOISE knob
Section	VCO (Voltage Controlled Oscillator)
Sound source	White noise from the noise generator
What it changes	The amount/level of white noise mixed with the VCO output
Lowest setting	Little or no white noise is mixed in
Higher setting	More white noise is mixed into the synth sound
Related signal path	The VCO output, including noise and any AUDIO IN signal, continues through the VCF and VCA

The manual documents the NOISE knob’s function, but it does not provide numeric level values or a way to infer the knob’s current position.
