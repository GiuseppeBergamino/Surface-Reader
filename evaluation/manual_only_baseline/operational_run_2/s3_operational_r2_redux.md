Prompt: Which control should I use to change the oscillator octave? Describe where it is and what it does.

Response:

Use the OCTAVE selector.

It is in the Synthesizer section, at the upper left of the main control panel, identified as control 1 in the manual’s panel diagram. It sits near the WAVE select switch and above the other VCO controls.

What it does: the OCTAVE selector specifies the VCO pitch in steps of an octave. The manual notes that with the “64’” setting, the ribbon keyboard’s pitch range is A0–D2.

One limitation: if the RANGE select switch is set to WIDE, the manual says the OCTAVE selector will be ignored.
