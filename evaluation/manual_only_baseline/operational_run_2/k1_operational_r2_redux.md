Prompt: Which control should I use to change the filter cutoff? Describe where it is and what it does.

Response: 

Use the CUTOFF knob in the VCF section.

It is in the synthesizer section, in the filter area. In the manual’s panel diagram it is control 5, directly paired with the PEAK knob, control 6. On the panel, this filter pair sits below the earlier VCO controls and above the VCA LEVEL area.

The CUTOFF knob adjusts the cutoff frequency of the VCF. Turning it left darkens the sound; turning it right brightens the sound. The manual describes the VCF as the filter that changes the timbre by boosting or cutting frequency regions, using a 12 dB/oct low-pass filter.
