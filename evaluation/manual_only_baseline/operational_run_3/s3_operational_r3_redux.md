Prompt: Which control should I use to change the oscillator octave? Describe where it is and what it does.

Response:

Use the OCTAVE selector.

It is in the Synthesizer section, at the upper left of the main control panel, immediately left of the VCO WAVE select switch. In the manual’s synthesizer panel diagram, it is control 1.

It changes the VCO pitch in octave steps. The manual says that with the “64’” setting, the ribbon keyboard pitch range is A0–D2. Note that if the RANGE select switch is set to WIDE, the OCTAVE selector is ignored.
