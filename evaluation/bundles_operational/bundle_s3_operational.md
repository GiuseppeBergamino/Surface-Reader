Prompt ID: s3

Prompt: Which control should I use to change the oscillator octave? Describe where it is and what it does.

# Surface Reader:
## R1:
Use the OCTAVE selector.

It is in the VCO section, near the upper-left area of the top panel. From the performer’s perspective, start at the top-left corner of the main control area and find the first oscillator control. It is a rotary selector, not a smooth continuous knob: it selects fixed octave positions.

What it does: the OCTAVE selector changes the VCO pitch in octave steps. In other words, it shifts the synthesizer oscillator higher or lower by whole octaves. The manual notes that with the 64' setting, the ribbon keyboard range is A0–D2. One important exception: when the RANGE select switch is set to WIDE, the OCTAVE selector is ignored.

I cannot tell what octave it is currently set to from the manual or static panel photo alone.
